# Design principles

Короткий канон публичного UI. Стек — [tech-stack.md](./tech-stack.md) §8. Страницы ленты и статьи собираются из этого, не из новых одноразовых классов.

## Намерение

Спокойный editorial: тёплая бумага, чернила, сильная типографика, мало визуального шума. Админка Payload этот файл не импортирует и этими токенами не красится.

## Где живёт система

| Что                           | Где                                                                                 |
| ----------------------------- | ----------------------------------------------------------------------------------- |
| Токены, шкала, Tailwind       | [`src/app/(frontend)/globals.css`](<../src/app/(frontend)/globals.css>)             |
| Примитивы                     | `src/components/ui` — button, input, label, textarea, separator, badge, card        |
| `cn`                          | [`src/lib/utils.ts`](../src/lib/utils.ts) реэкспортирует пакет `cn`                 |
| Иконки                        | `lucide-react`                                                                      |
| Легаси home / auth / switcher | [`src/app/(frontend)/styles.css`](<../src/app/(frontend)/styles.css>) до шагов 048+ |

Новый компонент из реестра: `npx shadcn@latest add <name>` (в `components.json` стиль `radix-nova`, база Radix). Не ставить npm-пакет `shadcn` в зависимости приложения: это CLI. Варианты `data-open` / `data-horizontal`, которые нужны примитивам, уже лежат в `globals.css`.

Tailwind сканирует только публичный фронт и `src/components`, не `(payload)`.

## Цвет

Роли shadcn, не сырые hex в компонентах. Светлая тема — тёплая бумага около `#f7f4ef` и чернила. Тёмная — тёплый почти-чёрный и тёплый off-white, не `#000` / `#fff`.

`primary` — чернильный синий (светлая тема близко к `#1a4d6d`, в тёмной светлее, чтобы текст на кнопке читался). `accent` в shadcn — это тихая подложка hover, не цвет ссылки. Ссылки и основные действия — `primary`.

Класс `.dark` переопределяет те же переменные на поддереве. Сейчас сайт всегда светлый: `prefers-color-scheme` тему не включает. Переключатель, запись выбора и отсутствие вспышки — шаг 047; он вешает `.dark` на `<html>`.

`--bg` и `--fg` в `styles.css` остаются как есть. Имена `--muted` и `--accent` заняты ролями shadcn, поэтому легаси-файл держит те же цвета как `--legacy-muted` и `--legacy-accent`.

## Типографика

| Роль    | Класс                         | Зачем                                       |
| ------- | ----------------------------- | ------------------------------------------- |
| Display | `text-display`                | Крупный заголовок первого экрана            |
| H1–H3   | `text-h1` `text-h2` `text-h3` | Заголовки                                   |
| Lead    | `text-lead`                   | Вводный абзац                               |
| Body    | `text-body`                   | Длинное чтение, мера `max-w-measure` (65ch) |
| Small   | `text-small`                  | Chrome, даты, мета                          |

Чтение — `font-serif` (Source Serif 4). Интерфейс — `font-sans` (Source Sans 3). Оба с кириллицей: Newsreader её не содержит, поэтому не он. На `<html>` только CSS-переменные шрифтов. `body` в `styles.css` всё ещё Georgia, и это неслоиное правило побеждает Tailwind на текущих страницах. Новый экран сам ставит `font-serif` / `font-sans`.

## Витрина

`/uk/dev/design` (и `/ru`, `/en`) показывает шкалу, свотчи и примитивы в двух колонках, light и `.dark`. Это леса, не пункт навигации, страницу не индексируем. Текст витрины английский, как у временного rich-text preview, плюс образец uk/ru в теле текста.
